# 检查项与严重度判据

## 六类检查项（facet）

| key | 名称 | 覆盖内容 |
|-|-|-|
| `structure` | 整体质量与结构完整性 | 章节齐备、层级合理、摘要与正文对应、结论回应引言 |
| `consistency` | 事实一致性与引用支持 | 摘要/正文/图表数值一致；引用标记与文献列表对应；术语统一 |
| `methods` | 方法设计与统计报告 | 对照、样本量、随机化、盲法、重复；p 值、CI、效应量、α、多重比较 |
| `argument` | 论证链与逻辑一致性 | 假设→结论路径、循环论证、因果/相关混淆、外推超范围 |
| `ethics` | 学术规范与可发表性 | 数据可用性、伦理审批、利益冲突、经费、作者贡献 |

## 严重度

| 级别 | 判据 | 例子 |
|-|-|-|
| `high` | 事实错误、引用不存在、数据与结论冲突、方法缺陷导致结论不可靠 | 正文引用 `[12]` 但文献列表无 12 |
| `medium` | 报告不全、结构缺位、数值只在摘要出现 | 无数据可用性声明 |
| `low` | 规范问题、可改进建议 | 参考文献未被引用、过度措辞 |
| `info` | 已检测到，供人工确认 | 检测到样本量表述 |

## 状态

| 状态 | 含义 |
|-|-|
| `问题` | 确定存在，需修改 |
| `证据不足` | 缺少判断依据，需补充材料或原文 |
| `建议` | 可改进，非必须 |
| `待复核` | 确定性脚本无法判定，需人工/模型 |
| `通过` | 该检查项已覆盖 |
| `未检查` | 未执行（列入 `unchecked_facets`，不混入结论） |

## 误报抑制

- 学科差异：CS 论文没有医学伦理声明，应标记 `待复核` 并注明可能不适用，而不是 `问题`。
- 期刊格式差异：不把排版、引用样式差异当缺陷。
- 作者有意取舍：摘要中的约数与正文精确值不必然冲突，需人工确认。
- 脚本无法判定的，一律降级为 `待复核`，不升级为 `问题`。

## 模型判断的边界

模型补充的 finding 必须：
1. 带段落索引与原文引用；
2. 标注 `method: model-judgment`；
3. 区分"错误"与"证据不足"；
4. 不重复确定性脚本已覆盖的条目。
